# rar4k world — avatar list

The VRChat world downloads `avatars.json` when a player joins (and re-checks every few minutes).
Edit the file here and commit — no world re-upload needed.

- Order in the list = order on the pedestals (6 per page, left → right as seen from the spawn).
- `name`   — text on the pedestal nameplate.
- `id`     — public avatar ID (`avtr_...`). Private avatars will not show.
- `medium` — optional ID of the Medium version. If set, the pedestal gets "◀ Обычная / Medium ▶" arrows.
- `tag`    — optional short badge shown after the name, e.g. `NEW`.
- `desc`   — optional short description, shown in small text under the name.

Names/descriptions are taken from the VRChat avatar pages. Full-width symbols like ［］＋ are written as plain [ ] + (the world font has no full-width glyphs).

Raw URL used by the world:
https://raw.githubusercontent.com/Kevanko/rar4k-world-avatars/main/avatars.json
